# App Shell 视觉规范

## 视觉基准

- 概念图：`docs/design/app-shell-concept.png`
- 原生画布：1586 × 992
- 页面类型：教师登录后的作业空状态
- 背景：主画布纯白，侧栏纯白，不使用渐变或图片叠色

## 组件结构

- `AppShell`：桌面侧栏、移动端顶部栏和主内容区。
- `Sidebar`：品牌、主导航、收起按钮；桌面固定，窄屏折叠。
- `Topbar`：语言切换和教师账户入口。
- `PageHeader`：标题、说明和创建作业操作。
- `EmptyAssignments`：空状态图标、说明和创建作业操作。
- `Icon`：统一 2px 圆角描边，使用 `currentColor`，不引入图标依赖。

## 交互与响应式

- `作业` 默认选中；导航可切换选中状态并更新主标题。
- 两个“创建作业”按钮打开同一个可关闭的创建提示面板，用真实本地状态证明交互链路。
- `中 / EN` 切换全部当前界面文案。
- `中 / EN` 同步更新页面语言和导航无障碍名称。
- `教师` 账户入口显示当前角色和后续账户管理阶段。
- `收起` 控制桌面侧栏宽度；小于 760px 时使用紧凑顶部布局。
- 所有按钮和导航必须有键盘焦点样式，并尊重 `prefers-reduced-motion`。
